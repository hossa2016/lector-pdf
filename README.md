# Lector PDF

Lector de PDF personal para Android. Se abre desde WhatsApp, Gmail, Drive o el gestor de archivos con "Abrir con… Lector PDF".

- Recuerda la página donde ibas
- Modos Normal, Sepia y Noche
- Zoom, búsqueda de texto y pantalla completa
- Funciona sin internet (usa PDF.js de Mozilla)

La APK se compila sola con GitHub Actions en cada cambio. Descárgala en **Releases**.
